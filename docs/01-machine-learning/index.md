# Part I — Machine Learning

> Build a strong foundation in machine learning and understand how models are trained, evaluated, and applied in production systems.

![Machine Learning Banner](../assets/banners/machine-learning-banner.png)

## Overview

Machine Learning (ML) enables systems to learn patterns from data and use them to make predictions or support decisions.

This Part follows the journey from core concepts and algorithms to data preparation, feature engineering, model evaluation, and practical modelling pitfalls. It is designed for software engineers, backend developers, cloud engineers, and solution architects who want to connect machine learning concepts with real application and enterprise systems.

The learning progression is:

```text
ML foundations
     ↓
Regression and classification
     ↓
Data preparation and feature engineering
     ↓
Ensemble and unsupervised learning
     ↓
Model evaluation and validation
     ↓
Reliable modelling practices
```

## What you will learn

By completing these chapters, you will be able to:

- Explain the differences between AI, machine learning, and deep learning.
- Distinguish supervised and unsupervised learning problems.
- Understand common regression, classification, tree-based, and ensemble algorithms.
- Prepare data and engineer features for model training.
- Evaluate models using appropriate metrics and validation strategies.
- Recognise overfitting, underfitting, bias-variance trade-offs, and data leakage.
- Understand clustering and dimensionality reduction techniques.
- Connect model development practices to production ML systems.

## How the topics fit together

The chapters cover three connected areas of machine learning:

### 1. Learning algorithms

Understand how models learn from labelled and unlabelled data, including regression, classification, decision trees, support vector machines, nearest neighbours, ensemble methods, and clustering.

### 2. Data and model quality

Explore feature scaling, feature engineering, dimensionality reduction, evaluation metrics, cross-validation, and regularization. These techniques help determine whether a model has learned useful patterns and whether its performance is likely to generalise beyond the training data.

### 3. Production perspective

Connect model development to practical systems. The production-focused chapters introduce classification and unsupervised learning systems, while the final chapters address validation and modelling pitfalls such as data leakage.

## Enterprise perspective

Machine learning supports a wide range of business capabilities, including:

- Fraud detection and credit risk analysis
- Recommendation systems and customer churn prediction
- Predictive maintenance and demand forecasting
- Intelligent search and predictive analytics
- Medical diagnosis and cybersecurity applications

The appropriate algorithm depends on the problem, the available data, the cost of errors, and the operational constraints. Model quality is only one part of a successful ML solution; data quality, validation, deployment, and ongoing monitoring matter too.
